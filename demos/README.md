## Data Rules

Every field that can be mistaken for evidence is labeled as one of:

- `public_source`
- `synthetic`
- `inferred_demo`

OpenAI and Anthropic are used as public-source example companies where official public pages support the claim. Salary, fit, score, warning flag, financial KPI examples, and any sensitive user/project data are synthetic unless explicitly labeled otherwise.
