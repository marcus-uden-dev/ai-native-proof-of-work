# System Boundaries

Last updated: 2026-05-08  
Status: Initial design

## In Scope

- Markdown documentation
- proof-of-work evidence mapping
- weekly logs
- recruiter assets
- strategy docs
- architecture docs
- Mermaid diagrams
- source maps
- local source index templates
- privacy and sharing checklist

## Out of Scope

- production app code
- autonomous sending of job applications
- raw email ingestion without approval
- public publishing without review
- storing secrets or credentials
- dumping raw chat transcripts
- exposing private local folder structures in recruiter-facing docs

## Human-Controlled Decisions

Marcus must approve:

- recruiter sharing
- public exports
- static strategy changes
- claims of measurable impact
- use of private or employer-related information
- promotion of recurring workflows into instructions/tasks
