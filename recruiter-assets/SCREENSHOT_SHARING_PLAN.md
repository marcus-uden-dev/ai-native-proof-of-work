# Screenshot Sharing Plan

Last updated: 2026-05-09
Status: Planned / Privacy review required

## Purpose

Screenshots would make the project evidence more concrete, but they should only be added after privacy review.

## Candidate Screenshot Set

| Project | Candidate Screenshot | Why It Helps | Privacy Check |
|---|---|---|---|
| Job-agent | Job discovery or job detail screen | Makes the lead proof point tangible | Remove personal profile data, real companies if sensitive, tokens, emails, names |
| Job-agent | CV/application assistant surface | Shows career workflow value | Use fake job and fake user data |
| Job-agent | Privacy/settings/data-rights surface | Shows trust/product maturity | Remove account identifiers |
| PKM | Search or knowledge capture surface | Shows information workflow | Use dummy notes and sources |
| Household budget app | Forecast/dashboard or import review flow | Shows domain modeling | Use synthetic financial data only |

## Rules

- Use synthetic or redacted data only.
- Do not show private local paths.
- Do not show real emails, phone numbers, tokens, credentials, addresses, personal finances, or confidential company data.
- Prefer 2-4 strong screenshots over a large gallery.
- Add captions that explain the product decision, not just the UI.

## Suggested Destination

Create `assets/screenshots/` only after screenshots pass review. Link them from the relevant case study.
