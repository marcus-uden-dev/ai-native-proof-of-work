# Interview Talking Points

Last updated: 2026-05-08  
Status: Initial draft

## 1. AI as an operating layer

I do not treat AI as a content shortcut. I use it as a layer for structuring work, extracting decisions, reducing repeated effort, and turning execution into reusable artifacts.

## 2. Proof of work over vague claims

The repository is built around evidence: what was done, what changed, what tradeoff was made, and what still needs validation.

## 3. Claude + Codex split

Claude is strongest for reasoning, synthesis, strategy, and evaluation. Codex is stronger for repository execution, file updates, and keeping documentation structured.

## 4. Documentation as compounding asset

Weekly logs, decision trails, and architecture docs make work easier to reuse in CVs, recruiter conversations, portfolio notes, and interviews.

## 5. Practical automation

The goal is not full autonomy. The goal is to automate repeatable work while keeping human review on important decisions.

## 6. Product + architecture thinking

The repository connects value proposition, business model, pricing, GTM, architecture, ingestion, and recursive workflows in one system.

## 7. Privacy-aware workflow design

Sensitive information is excluded, redacted, or generalized before anything becomes recruiter-facing.
