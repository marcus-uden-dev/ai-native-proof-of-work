# Job-Agent Value Proposition

Last updated: 2026-05-11
Status: Hypothesis / Internal evidence summarized

## Project Scope

Project: job-agent.

Role in portfolio: primary proof point and lead career workflow product.

## Core Claim

Job-agent helps job seekers turn scattered career material, job opportunities, application work, and feedback into a reviewed career workflow.

The value proposition is not "AI writes applications." The stronger value is a trustworthy career operating system: discover relevant jobs, adapt materials, support applications, preserve user control, and learn from outcomes.

## User Problem

Job search work is fragmented across CVs, job boards, application portals, interview notes, follow-ups, recruiter feedback, and personal constraints. Generic AI tools can generate text, but they do not reliably preserve context, reviewability, privacy, or outcome learning.

## Before

- Career material, job opportunities, and application drafts lived in separate places.
- Each application required repeated context reconstruction.
- It was hard to see which feedback, job criteria, or application choices improved outcomes.
- Automation risked becoming either too shallow or too autonomous to trust.

## After

- CV/profile material becomes part of a reusable workflow.
- Job discovery, fit analysis, application support, and feedback loops are connected.
- Human review remains central for quality, privacy, and trust.
- Product decisions around consent, data rights, telemetry, pricing, and deployment are explicit.

## Value Created

| Value | Explanation | Evidence Status |
|---|---|---|
| Reduced application friction | Reuses career context instead of restarting every application | Internal / Verified |
| Better reviewability | Keeps job analysis, generated material, and user feedback inspectable | Internal / Verified |
| Stronger privacy posture | Consent, data-rights, retention, and export/delete flows are part of product planning | Internal / Verified |
| Product learning loop | Feedback and outcomes can inform future suggestions and roadmap choices | Internal / Verified |
| Recruiter-relevant proof | Demonstrates full-stack product judgment in a real workflow domain | Internal / Verified |
