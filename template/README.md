# Template Adoption Kit

Last updated: 2026-05-18
Status: Active / Secondary audience

## Purpose

This folder contains the clone/fork/adoption material for people who want to reuse this proof-of-work system with their own repositories and evidence sources.

The main repository audience remains recruiters, hiring managers, and collaborators reviewing Marcus's proof of work. This folder is the reusable seed layer.

## Adoption Rule

When another user adopts this template, they should replace Marcus-specific project evidence with their own:

- product/source repositories
- weekly notes
- screenshots
- source summaries
- case studies
- local source roots
- automation runner
- recruiter-facing claims

Use this repository as structure and operating model, not as copied evidence.
