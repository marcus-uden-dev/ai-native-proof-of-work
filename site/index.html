How I work

A visible decision loop

The process is useful only when it produces evidence, a decision, or a smaller next test.

  1. 01DiscoverFind the real constraint.
  2. 02DefineChoose the decision and boundary.
  3. 03BuildCreate the smallest credible proof.
  4. 04ImproveTest, learn, and tighten.

Beneath it: a human-gated system loop

  1. 01ExecuteDo the work.
  2. 02ReviewCheck the output.
  3. 03Detect patternSpot what repeats.
  4. 04Human gateA person decides — not the system.
  5. 05PromoteTurn the pattern into reusable infrastructure.
  6. 06Next cycleRepeated work improves the next round.

Human review controls every promotion, change, and removal in this loop — see the Recursive workflow system for the Autoresearch and promotion examples.
